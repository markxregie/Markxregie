## linux commands i actually use

A running list of commands I reach for most when I'm poking around a network or a box.

```
$ ip addr show                 # check interfaces and IPs
$ ip route                     # view the routing table
$ ping -c 4 8.8.8.8             # basic reachability check
$ traceroute google.com        # trace the path a packet takes
$ ss -tulnp                    # see what's listening on which ports
$ netstat -rn                  # legacy route table view
$ tcpdump -i eth0              # capture traffic on an interface
$ sudo systemctl status ssh    # check a service's status
$ journalctl -xe               # dig into recent system logs
$ chmod 600 id_rsa             # lock down a private key
$ ufw status verbose           # check firewall rules
```
